# Растения — полив

- Монстера в гостиной: раз в неделю, по субботам, пока верхние 3 см земли сухие.
- Фикус лирата у окна: два раза в месяц, не переставлять — сразу сбрасывает листья.
- Кактусы на кухне: зимой (с ноября по февраль) не поливать совсем.
- Хлорофитум в спальне: часто, любит воду.
- Удобрение: с марта по сентябрь раз в две недели, половина дозы.
- Когда уезжаю больше чем на неделю, поливает фрау Мёллер вместе с кормлением Бублика.
