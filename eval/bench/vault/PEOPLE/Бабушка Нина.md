# Бабушка Нина

Нина Петровна, мамина мама. 89 лет, живёт в Зеленодольске одна, рядом соседка Валя.

- День рождения — 5 января.
- Плохо слышит по телефону, лучше звонить через маму по видео.
- Любит кроссворды, выписывает газету ради них.
- Научила меня печь пирожки с капустой: тесто на кефире, капусту тушить с яйцом.
- Каждое лето просит привезти ей семена укропа «нормального, не магазинного».
