# Мама

Людмила Сергеевна, живёт в Казани, на пенсии с 2023 года, до этого — учительница химии.

- День рождения — 23 ноября.
- Созваниваемся по воскресеньям вечером, в 19:00 по Казани (у меня 17:00).
- Давление: пьёт лозартан по утрам; не любит, когда я об этом спрашиваю.
- Любит гортензии, на даче у неё их пять кустов. Читает Улицкую.
- Не пьёт кофе после обеда, но обожает портвейн, который я привёз из Порту.
