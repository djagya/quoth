# Portuguese grammar cheat sheet

- ser vs estar: ser for what something is (sou engenheiro), estar for a state (estou
  cansado). Location of things: estar; of events: ser.
- por vs para: por = through, by, in exchange for; para = towards, in order to.
- Personal infinitive: "é melhor irmos agora" (it is better that we go now).
- In Portugal "tu" is normal with friends; "você" can sound distant.
- False friends: puxar = pull (not push), esquisito = strange, constipado = has a cold,
  propina = tuition fee, not a tip.
- The "a gente" form takes the third person singular.
